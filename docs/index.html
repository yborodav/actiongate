Let agents act without the keys.

ActionGate holds your API credentials, sends risky agent actions to a person, and runs exactly what they approved, once. If nobody answers, nothing happens.

    Run it in 5 minutes

    Python 3.11 or newer, or Docker. Works with Claude Code, Cursor and the OpenAI Agents SDK through MCP.

    Install

    Clone the repo and run the tests.

    $ git clone https://github.com/yborodav/actiongate
$ cd actiongate
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -e ".[dev]"
$ python -m pytest -q

    Add keys and rules

    Credentials go into the vault, never into a file.

    $ export ACTIONGATE_VAULT_KEY=$(python -m actiongate vault-key)
$ python -m actiongate put-secret stripe_restricted_key
$ python -m actiongate new-key
$ cp actiongate.example.yaml actiongate.yaml

    Connect your agent

    Start the server and point any MCP client at it.

    $ python -m actiongate serve --config actiongate.yaml

$ claude mcp add --transport http actiongate \
    http://localhost:8080/mcp/ \
    --header "Authorization: Bearer $AGENT_KEY"

    Built to fail closed

    Open source under Apache-2.0, so you can read every line that stands between your agent and your money.

    default deny

    Unknown tool, no matching rule, failed pre-check or no answer in time: nothing runs.

    approvals bound to the action

    Each approval issues a signed, single-use grant tied to a hash of the exact parameters.

    checked before anyone is asked

    A refund larger than what's left on the charge is rejected before it reaches an approver.

    tamper-evident audit

    Every decision is hash-chained and signed. One command proves nothing was edited or removed.

    your own APIs too

    Turn any internal endpoint into a gated tool with a few lines of YAML.

    agent text can't spoof approvers

    Values the agent supplies are escaped before they're shown in Slack.
